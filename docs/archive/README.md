# Archivierte Dokumentation

Dieses Verzeichnis enthält Dokumente, die abgeschlossene Arbeitsstände dokumentieren und nicht mehr den aktuellen operativen Stand des Projekts beschreiben.

## migration-v1

`migration-v1/` archiviert den Übergang vom Legacy-Bestand in `.oldrepo` zur modularen Architektur bis zum dokumentierten Release-Stand `v1.1.0`.

Die Dateien bleiben erhalten, weil sie frühere Architekturentscheidungen, Paritätsbewertungen, Inventuren und Release-QA-Ergebnisse nachvollziehbar machen. Sie sind keine aktuelle Arbeitsanleitung mehr.

Aktuelle technische Referenzen stehen weiterhin im aktiven Dokumentationsbereich, insbesondere:

- [Technische Architektur](../TECHNICAL-ARCHITECTURE.md)
- [Runtime-Entrypoints](../RUNTIME-ENTRYPOINTS.md)
- [Performance-Audit](../PERFORMANCE-AUDIT.md)
- [Legacy-Konfigurationspfade](../LEGACY-CONFIG-DEPRECATION.md)

Der frühere Agent-Skill `oldrepo-parity-recovery` ist unter `migration-v1/agent-skills/oldrepo-parity-recovery/` archiviert. Er war auf die abgeschlossene Legacy-Paritätsarbeit ausgerichtet und wird im aktiven Skill-Verzeichnis nicht mehr referenziert.
