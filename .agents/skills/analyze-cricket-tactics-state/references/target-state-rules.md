# Target State Rules

- Cricket domain targets are the game targets and bull state represented by the current domain model.
- Tactics official domain targets exclude DOUBLE and TRIPLE.
- DOUBLE and TRIPLE may be parsed for host DOM compatibility only when needed to read the page correctly.
- Grid coloring reflects domain target state.
- Board coloring reflects the active player's perspective.
- Shared parsing/state helpers are preferred over feature-local reinterpretation.
